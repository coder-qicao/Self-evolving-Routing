# Model Routing — Empirical Comparison

**Status:** v1 (2026-05-20). Built from `memory/routing/index.jsonl`, 33 runs
across 7 tasks × 3 models. **Caveat:** every recorded run used a *single*
model for all sub-agents (no per-role mixing yet), so per-role cost numbers
below are real, but per-role *quality* of each model is still inferred from
overall-run outcomes.

---

## TL;DR for the manager

When routing a new task, start with this heuristic:

| Situation | Recommended routing |
|---|---|
| Known task (`detecting-insults-in-social-commentary`) | All roles → `claude-haiku-4-5` (gold for ~$5) |
| Unknown task, looks "easy" (text classification, small tabular, small image) | All roles → `claude-sonnet-4-6` (best $/quality in our data) |
| Unknown task, looks "hard" (medical segmentation, large image, multi-modal) | Manager + tuner → `claude-opus-4-7`; setup + designer + coder → `claude-sonnet-4-6` |
| Sonnet/haiku previously failed on this task | Bump *coder* and *tuner* to `claude-opus-4-7`; keep rest cheap |

Two opinionated rules of thumb derived from the data below:

1. **Tuner is by far the biggest cost center** (~40–60% of total). If you
   have to downgrade ONE role to save money, downgrade the tuner first.
2. **For easy tasks, opus buys nothing over sonnet.** On 3/7 tasks
   (detecting-insults, nomad2018, aerial-cactus) sonnet and opus got the
   **same medal** while opus cost 2–8× more.

## Per-role cost share (computed from 19 graded runs in `index.jsonl`)

| Role | Share of total | $/role @ haiku | $/role @ sonnet | $/role @ opus | opus/haiku ratio |
|---|---:|---:|---:|---:|---:|
| tuner | **53.6%** | $2.61 | $7.11 | $25.59 | 9.8× |
| coder | **31.3%** | $1.88 | $3.02 | $13.94 | 7.4× |
| judge | 7.0% | $0.44 | $0.93 | $2.64 | 6.0× |
| designer | 4.4% | $0.14 | $0.39 | $1.91 | 13.4× |
| setup | 1.8% | $0.07 | $0.14 | $0.72 | 10.7× |
| aggregator | 1.5% | $0.06 | $0.14 | $0.81 | 14.0× |
| manager | 0.0% | $0 | $0 | $0 | — (cached / persistent) |

**Reading this:** the manager itself is free (cache + persistence). All the
money is in `tuner` and `coder`, in that order. Cheap roles like
`aggregator`, `setup`, `designer` barely matter for the bill — keeping them
on opus costs almost nothing absolute, even if the ratio looks bad.

## What we still don't know

- **Per-role-mixed routing has never been tested.** All numbers here come
  from runs where every role used the same model. We assume role-level cost
  carries over linearly when models are mixed — this is the next experiment
  to run.
- **Why some runs went `none`** (sonnet on detecting-insults, sonnet on
  jigsaw, etc.) — could be a transient model error, a coder bug, or a real
  capability gap. Pre-pkill / pre-rate-limit, we don't have enough data
  to separate.
- **The `manager` role shows $0**. This is the orchestrator's persistent
  session — its cost likely ends up attributed to nothing because it
  reuses cache aggressively. Worth verifying with raw API logs before
  assuming "manager is free regardless of model".
